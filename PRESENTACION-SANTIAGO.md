# Guion de demostración · SROI Studio (v0.3)

**Propósito de esta entrega:** mostrar una propuesta de producto digital desde Diseño de Medios Interactivos para hacer aplicable y comprensible el modelo del trabajo de grado. Es un MVP de experiencia y contenido, **no** una herramienta certificada de cálculo de impacto.

## Recorrido sugerido (6–8 minutos)

1. **Vista general (45 s).** Presentar el problema: la gestión pública puede medir entregables y presupuesto, pero necesita evidenciar qué cambia para los beneficiarios. Mostrar la portada, la navegación y los proyectos de ejemplo.
2. **Mis proyectos (45 s).** Crear un proyecto de prueba y explicar que la plataforma busca gestionar distintas evaluaciones; los datos del proyecto se guardan *solo en este navegador*, no en un servidor.
3. **Evaluación SROI (2 min).** Navegar las seis etapas. Enseñar las orientaciones metodológicas, preguntas guiadas, recomendaciones y guardado de respuestas. Responder algunos campos y usar **Guardar y continuar**.
4. **Biblioteca SROI (1 min).** Mostrar el contexto territorial, las seis etapas, hallazgos validados, fuentes, pendientes metodológicos y la clara distinción entre contenidos aprobados y faltantes.
5. **Resultados (1 min).** Mostrar el caso de referencia, con ratio académico **0,17:1** y sus límites. Cambiar a un proyecto nuevo para demostrar que el sistema **no inventa** un ratio.
6. **Informes (45 s).** Mostrar la portada de informe, **Imprimir / Guardar en PDF** y exportar las respuestas a JSON para conservar el trabajo.
7. **Cierre (30 s).** Definir qué se necesita para pasar de demo a herramienta real: fichas originales, catálogo de indicadores, proxies, datos, validaciones y backend.

## Confirmado en las fuentes aportadas

- Autor: Santiago Medina Cruz; Maestría en Gerencia de Proyectos, Universidad Icesi (octubre de 2026).
- Objetivo: adaptar SROI a programas territoriales de fortalecimiento empresarial.
- Seis etapas, siete instrumentos diligenciables, tablero y plantilla de reporte público.
- Aplicación retrospectiva: inversión de 12.154 millones COP, 780 unidades productivas, 260 con visitas, ratio parcial 0,17:1.
- En el caso se monetizaron cinco de trece indicadores según el resumen ejecutivo.
- Revisión de seis expertos y limitaciones documentadas.

## Limitaciones honestas de la demo

- Los campos orientativos de las etapas **no sustituyen** las siete fichas originales.
- No hay autenticación, base de datos central ni trabajo multiusuario.
- Los proyectos/respuestas se guardan con localStorage y pueden desaparecer al borrar datos del navegador.
- El ratio de referencia no se recalcula; solo proviene del caso académico.
- La impresión genera una **portada conceptual**, no un informe SROI auditado.
- No almacenar información personal o sensible de beneficiarios en esta demo.
